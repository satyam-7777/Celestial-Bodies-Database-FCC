# Build a Celestial Bodies Database

A PostgreSQL database project completed as part of the **freeCodeCamp Relational Database Certification**.

## Project Overview

This project involves building a relational database of celestial bodies using **PostgreSQL**.

The database is designed to store information about different types of celestial bodies and their relationships. The project focuses on creating tables, defining relationships, inserting data, and satisfying the required database constraints and tests.

## Features

- PostgreSQL relational database
- Multiple related tables for celestial bodies
- Primary and foreign key relationships
- Structured relational data
- Required data inserted into the database
- Database tests completed successfully
- Database exported as a `universe.sql` dump file
- Project submitted through a public GitHub repository

## Technologies Used

- PostgreSQL
- SQL
- Git
- GitHub

## Database Structure

The database contains the following main tables:

- **Galaxy**
- **Star**
- **Planet**
- **Moon**

These tables are related using PostgreSQL primary and foreign keys to represent relationships between celestial bodies.

## Data Included

The database contains the required number of records for the project:

- At least 6 galaxies
- At least 6 stars
- At least 12 planets
- At least 20 moons

The database also includes the required relationships between the celestial bodies.
